# SPNGの読み取り仕様

このビューアが扱うSPNGは、PNG画像を次の順序で連結したコンテナです。汎用の別ライブラリ「libspng」のファイル形式を指すものではありません。

1. PNGのbyte長を表すlittle-endian uint64（8 bytes）
2. その長さのPNGデータ
3. 次の層の長さとPNGデータを繰り返す

uint64が0、またはUINT64_MAX（2^64−1）の場合、その層は欠損として扱います。欠損でも層番号は詰めません。

開く際は長さとPNGヘッダだけを走査して索引を作り、必要な層を遅延展開します。PNGの署名・IHDR・サイズと、ファイル内に収まるデータ長を確認します。切れたヘッダや不正な長さはエラーです。

センサーフォルダ名は00_00などの数字2桁_数字2桁を使います。通常のファイル名は次の構造です。

    画像種別_8桁View番号_Layer番号_層数.spng

例：

    Raw_0_00000012_1_032.spng

画像種別はRaw_0、Viewは12、Layerは1です。ファイル名の層数より、実際に格納されているコンテナ索引を優先します。

画像座標は表示上、左下原点です。PNG内部の行配列は上から下の順序です。切り出し時には、画面で指定した左下原点の座標をPNGの上から始まる行座標へ変換します。

PNG出力は入力SPNGを書き換えず、別の.pngファイルに保存します。SPNGへの書き戻し機能はありません。
