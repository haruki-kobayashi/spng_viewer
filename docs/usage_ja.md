# 操作説明

## 画像の選択

「ファイルを開く」はSPNG単体を開きます。「フォルダを開く」はIMAGE、DATA、その一つ上の階層、またはセンサーフォルダを選べます。センサー、Layer、画像種別、View、ファイルを選択して切り替えます。大規模データ全体の再帰走査や全コピーは行いません。

プルダウンは最大12行で、残りはスクロールします。

## 表示と切り出し

- 左ドラッグ：画像を移動
- Ctrl＋左ドラッグ：範囲選択
- ホイール：層送り
- Ctrl＋ホイール：拡大縮小
- 全体表示：画像全体を収める
- 100%：画像1pixelを画面1pixelで表示

Xは右向き、Yは上向き、原点は画像の左下です。カーソル座標と画素値を画面下部に表示します。座標入力のX,Yは領域の左下、幅と高さはpixel数です。

「表示層をPNG保存」「範囲をPNG保存」は実際の画素値を保存します。表示の反転、表示濃淡の調整、選択枠は入りません。処理段階を表示中なら、その段階の画素値を保存します。0/1の二値画像はPNGでも0/1のまま保存します。

8bit grayscale、16bit grayscale、8bitカラー等に対応します。16bitカラーは情報損失を避けるため、変換せずエラーとします。

## 再生・追従

開始層・終了層は両端を含みます。送り間隔、層/秒、ループON/OFFを指定します。ループOFFでは終端で停止します。読み込みが遅いときは層を飛ばさず、再生が遅くなります。

「再生前に全層を先読みする」をONにすると、元画像をディスクキャッシュへ展開してから再生します。パレット形式のPNGを含むSPNGでは全層先読みを使用できません。通常の層表示は使用できます。

異なる層で2点を登録すると、層番号で線形補間した位置が画面中央に来るように表示を移動します。座標は**元SPNGの座標**です。画像処理で拡大していても元座標へ対応づけます。

2点の外側へ直線を延長するか選べます。Zの物理距離ではなく層番号に沿う補間です。リセットはその点の入力と登録を消し、追従を解除します。別の2点を指定するときは両方をリセットしてください。

追従は表示の移動だけです。PNG出力や重ね合わせで画像を位置合わせする機能ではありません。

## 重ね合わせ・出力

層の指定例：

- 0-31：層0から31まで
- 0-31:2：層0,2,4,...,30
- 1-31:2：層1,3,5,...,31
- 0-15,20,25-31：複数範囲の和集合

欠損層は除外し、重複指定は1回として扱います。

最大値・最小値は同じXY画素を層の間で比較します。同値の場合は小さい層番号を採用します。グレースケール画像に対応します。

色分けでは極値を与えた層番号をkingfisher / meadow / ember / heat / rainbowで表示します。カラーバーの左が小さい層番号、右が大きい層番号です。明度変化は最大値では明るさ、最小値では暗さを使います。カーソル表示には極値を与えた層番号も出ます。色分けした画像はRGBとして保存します。

複数層PNG出力は、現在の元画像／処理段階を対象にします。保存先に新しい専用フォルダを作り、層ごとのPNGとexport_manifest.jsonを保存します。「選択範囲だけ」をONにすると、各層の同じ画像座標を切り出します。

途中で中止した場合は保存済み画像を残し、記録に中止状態を残します。

## スキャン設定の読み込み

画像処理タブの「スキャン設定を自動読み込み（Layer別）」は初期状態でONです。画像を開くと、撮像フォルダの`PARAMS/CombinedParam.json`を優先して検索し、画像ファイル名のLayer番号に対応する設定を読み込みます。Layerは乳剤面の番号で、表示する断層画像の層番号とは別です。

読み込み元のパス、設定対象Layer、二値化閾値の計算式を画面に表示します。設定を読み込んだ後、「設定を現在のspngの全層へ適用」を押すと画像処理を実行します。設定JSONを直接選ぶこともできます。

自動読み込みがONの場合はファイル切り替えに合わせて設定を更新します。手動調整した値を保持する場合はOFFにしてください。設定が見つからない場合はビューアの初期値を表示します。該当Layerがない場合や設定が不正な場合は処理ボタンを無効にし、理由を表示します。別Layerの値は流用しません。

[対応パラメータと検出規則](scan_parameters_ja.md)

## 全層画像処理

順序は、画素補間 → 2D filter → Z filter → 二値化 → 膨張です。有効な段階だけを実行します。8bit grayscaleに対応し、全段階・全層を一度計算してから表示します。

| 設定 | 設定ファイルがない場合の初期値 | 上下ボタン／ホイールの刻み |
| --- | --- | --- |
| 画素補間 | ON | — |
| 補間倍率 | 1.4142 | 0.0001 |
| 補間方式 | GPU形式 A=-0.5 | — |
| FIR tap数 | 15 | — |
| NormCutOffFreq | 0.1 | 0.01 |
| Z filter係数 | −0.2 | 0.01 |
| Z参照間隔 | 前後1層 | — |
| 二値化閾値 | 9 | — |
| 膨張 | ON、2×2 | — |

画素補間／膨張はOFFにしても設定値を保持します。

- **GPU形式の補間**：A=-0.5、整数原点cubicをCPU上で模擬します。GPUは不要です。
- **CPU cubic**：OpenCV INTER_CUBICを使います。GPU形式と同じではありません。
- **2D filter**：Hamming FIRで背景Bを求め、H=max(B−I,0)を計算します。
- **Z filter内部**：H(z) + 係数/2 × sat8[H(z−d)+H(z+d)]。端は片側参照を全係数で使い、欠損参照は中心層で代用します。
- **Z間隔d=2**：偶数層・奇数層を独立に処理します。16層スキャンの模擬では、再生・出力も片方の偶奇に揃えてください。
- **二値化**：値>閾値なら1、その他は0です。
- **膨張**：n×nの正方形。n=1は変化なしです。二値化ON時に使います。

途中段階はuint8へ丸め・飽和します。XYのFIR端はreflect101です。

キャッシュはexe／ソース隣のcacheフォルダに作成します。書き込みできない場所ではOSの一時フォルダへ切り替えます。ファイル切り替え・処理更新・通常終了時に解放します。異常終了時には残る場合があります。

読み込んだ設定は画像処理タブで調整できます。読み込み時の数値は表示桁数を超える精度も保持し、その項目を変更しない限り画像処理に使用します。
