# SPNG Viewer 利用ガイド

SPNG Viewerは、SPNGに格納された断層画像を閲覧し、指定範囲の切り出し、層送り、経路への表示追従、最大値・最小値の重ね合わせ、画像処理、PNG保存を行うWindows用アプリです。このガイドでは、画面の項目名に沿って操作と結果を説明します。

## 起動と最初の操作

ビルド済みの`out/app/SPNGViewer.exe`を起動します。ビルド方法は[BUILDING.md](../BUILDING.md)にあります。配布されたexeは任意のフォルダから直接起動でき、追加ライブラリのインストールは不要です。Windows 10 / 11 x64向けで、検証環境はWindows 11 x64です。

画像を1枚保存するまでの基本操作は次のとおりです。

1. 「ファイルを開く」でSPNGを選びます。
2. 画像下のスライダー、層番号、または画像上のホイールで表示する層を選びます。
3. 必要ならCtrl＋ホイールで拡大し、左ドラッグで表示位置を動かします。
4. 全体を保存する場合は「表示層をPNG保存」を押します。
5. 一部だけ保存する場合はCtrl＋左ドラッグで範囲を選び、「範囲をPNG保存」を押します。

保存されるのは画像の画素値です。画面の枠、カーソル、表示濃淡、表示倍率を含むスクリーンショットではありません。

## 用語と画面の構成

| 用語 | このアプリでの意味 |
| --- | --- |
| センサー | `00_00`などのセンサーフォルダで区別する画像群 |
| View | 視野番号。ファイル名から取得する |
| Layer | ファイル名やスキャン設定の乳剤面番号。例：Layer0、Layer1 |
| 層／層番号 | 1つのSPNGの中に並ぶ断層画像の番号。0始まり |
| 元画像 | 現在開いているSPNGに保存された画像。画像種別が処理済みデータの場合、それもこのアプリでは「元画像」と呼ぶ |
| 表示データ | 元画像または画像処理後の段階。保存・重ね合わせ・一括出力の対象を決める |
| 選択範囲／ROI | 切り出す長方形。単位はpixel |
| 追従 | 異なる層の2点を結ぶ位置が画面中央に来るよう、表示位置を動かす機能 |

**Layerと層番号は別のものです。** たとえば「Layer1のSPNGにある層20」を表示できます。Layerを変えると別ファイルを開き、層番号を変えると同じファイル内の別断層画像を表示します。

画面には上部ツールバー、左側の4つのタブ、画像表示領域、画像下の層送り・再生操作、状態表示があります。

| 場所 | 主な内容 |
| --- | --- |
| 上部ツールバー | ファイル／フォルダを開く、PNG保存、全体表示、100%、倍率表示、使い方 |
| 「画像」タブ | ファイル選択、画像情報、切り出し座標、表示濃淡 |
| 「再生・追従」タブ | 再生範囲・間隔、先読み、2点登録、追従設定 |
| 「重ね合わせ・出力」タブ | 対象層、最大／最小合成、層番号色分け、複数層PNG出力 |
| 「画像処理」タブ | 表示データ、スキャン設定、各フィルタ、全層への適用 |
| 画像下 | 再生／一時停止、速度、ループ、前後の層、スライダー、層番号 |
| 下部の状態表示 | 読み込み・処理・保存の進捗、エラー、カーソル座標と画素値 |

タブ内の項目が画面に収まらないときは、タブ内をスクロールします。フォントはシステム標準フォントです。

## 画像の選択

### 開ける対象

| 操作 | 選ぶもの |
| --- | --- |
| ファイルを開く | 単一の`.spng`ファイル |
| フォルダを開く | `IMAGE`、`DATA`、その直上の撮像フォルダ、`00_00`などのセンサーフォルダ、またはSPNGを直接含むフォルダ |
| ドラッグ＆ドロップ | ファイルまたはフォルダをアプリへドロップ。複数を渡した場合は最初のファイルシステム上の対象を開く |

直上の撮像フォルダを開いた場合、その直下にあるIMAGE／DATAを「画像フォルダ」で選べます。任意の深さまで全データを再帰検索する機能ではありません。目的の撮像フォルダ付近を指定してください。

### フォルダ内での切り替え

「画像フォルダ」→「センサー」→「Layer」→「画像種別」→「View（入力可）」→「ファイル」の順で絞り込みます。選択肢は実際に存在するファイルから作られます。同じViewに複数ファイルがある場合は最後の「ファイル」で選びます。

Viewは一覧から選ぶほか、番号を入力してEnterでも切り替えられます。たとえば`00000012`に対応するViewは`12`と入力できます。存在しないViewでは、その旨が状態表示に出ます。プルダウンの表示行数は最大12行で、残りはスクロールします。

ファイル名は次の形式を認識します。

```text
画像種別_8桁View番号_Layer番号_末尾の数字.spng
Raw_0_00000012_1_032.spng
```

この例では画像種別は`Raw_0`、Viewは12、Layerは1です。画像種別にアンダースコアが含まれていても識別します。末尾の数字から表示層数を決めることはなく、実際にファイルに格納された層を数えます。

命名規則に合わないファイルも単体で開けます。フォルダ一覧では「その他のファイル」「指定なし」として扱い、スキャン設定のLayerを自動判定できない場合は「設定Layer」を手動で選びます。

ファイルを開くと、最初に保存画像がある層を表示します。欠損層を含む場合も層番号は詰めません。32層なら番号は0～31です。

## 表示と座標

### 移動・拡大・層送り

左ドラッグで画像を移動し、Ctrl＋ホイールでマウス位置を基準に拡大・縮小します。右ドラッグと中ボタンドラッグでも移動できます。「全体表示」は画像全体を画面に収め、「100%」はビューアの拡大率を100%に戻します。Windowsの表示倍率によって、物理的なディスプレイpixelとの対応は変わります。

画像上での通常のホイールは層送りです。上方向は前の層、下方向は次の層です。「◀ 前の層」「次の層 ▶」、左右矢印キー、PageUp／PageDown、スライダー、層番号の直接入力も使えます。端の層で手動送りしても循環しません。

層を読み込んでいる間は前の画像を暗くせずに保持します。ただし、その間はカーソル値や保存を確定できないため、読み込み完了を待って操作してください。欠損層では画像がなく、保存もできません。

### 座標の原点

Xは右向き、Yは上向きで、左下pixelの座標が`(0, 0)`です。幅W、高さHの画像では右上pixelは`(W−1, H−1)`です。PNGの見た目の上下を反転しているわけではなく、座標の表示方法を左下原点にしています。

カーソルを画像内に置くと、画面下部にX、Y、画素値を表示します。カラー画像では複数成分の値を表示します。カーソルが画像外にあるときや読み込み中は「―」になります。

### 表示中の画像と元SPNGの座標の違い

| 使用箇所 | 座標の基準 |
| --- | --- |
| カーソルのX・Y | 表示中の画像のpixel |
| 切り出しのX・Y・幅・高さ | 表示中の画像のpixel |
| 追従点1・点2のX・Y | 元SPNGのpixel |
| 画面のズーム | 座標値を変えず、見せる倍率だけを変える |

画像処理の「画素補間」で画像を拡大・縮小すると、画像のpixel数が変わります。幅1000 pixelの元画像が幅2000 pixelになると、同じ付近を示す表示画像のX座標はおおむね2倍です。元画像の100×100 pixelに相当する範囲は、拡大後にはおおむね200×200 pixelになります。

追従点は、処理段階を変えても同じ元画像上の位置を参照できるよう、元SPNGの座標で保持します。処理後の画像上をクリックして登録した場合も、自動的に元座標へ換算します。内部の換算ではpixel中心を考慮し、幅の比をsxとすると、`表示X = (元X + 0.5) × sx − 0.5`です。Yにも高さの比で同じ式を使います。倍率設定から計算した画像サイズは整数へ丸めるため、換算には実際の画像サイズ比を使います。

一方、Ctrl＋ホイールのズームでは画像そのもののpixel数は変わりません。拡大して見てもカーソル座標や切り出し幅の意味は変わりません。

座標の単位はpixelです。µmへの換算、実空間のZ間隔、スキャン座標への変換を行う機能はありません。

### 表示濃淡と反転

「黒に対応する値」と「白に対応する値」で表示範囲を指定します。範囲外の値は表示上の黒／白に収まり、中間の値はその間の明るさになります。白の値は黒の値より大きくしてください。

「表示だけ白黒反転」は見た目を反転します。「元の階調へ戻す」は標準範囲へ戻し、反転も解除します。標準範囲は通常の8bit画像で0～255、16bitで0～65535、0/1画像で0～1です。

これらは保存画素を変更しません。たとえば表示範囲を0～24にしても、保存PNGを25階調に変換することはありません。層番号で色分けした重ね合わせを表示中は、色を保つため濃淡・反転操作を無効にします。

## 切り出し範囲

### マウスで選ぶ

画像内でCtrlを押しながら左ドラッグします。橙色の枠が選択範囲です。選択後は左下座標、幅・高さ、含まれるX・Yの範囲を表示します。「選択範囲へ拡大」でその範囲を大きく見られます。

### 数値で選ぶ

X、Y、幅、高さを入力し、「座標から範囲を指定」を押します。X・Yは長方形の**左下**です。

たとえば`X=100、Y=200、幅=50、高さ=40`なら、X=100～149、Y=200～239を含む50×40 pixelを選択します。幅・高さは1以上で、全体が画像内に収まる必要があります。

「解除」またはEscで選択を消します。範囲未選択では「範囲をPNG保存」を使えません。数値の入力だけでは範囲は更新されず、「座標から範囲を指定」で確定します。

同じ大きさの画像間では選択範囲を使い回せますが、別ファイルを開いたときや画像サイズが変わったときは解除されます。補間後の画像に切り替えた場合は、対象と座標を確認して選び直してください。

## 再生・追従

### 自動層送り

| 項目 | 意味・初期状態 |
| --- | --- |
| 開始層（含む） | 最初の層。ファイルを開いたときは0 |
| 終了層（含む） | 上限の層。ファイルを開いたときは最終層 |
| 層の間隔 | 一度に進む層数。初期値1、設定範囲1～10000 |
| 再生速度 | 1秒当たりの層送り回数。初期値8、設定範囲0.2～60 |
| ループ | 終了範囲を越えたら開始層へ戻る。初期状態ON |
| 再生前に全層を先読みする | 元画像を先読みしてから再生。初期状態ON |

「▶ 再生」で開始し、「⏸ 一時停止」で止めます。表示層が範囲内で終了層より前ならその位置から再生し、範囲外または終了層にある場合は開始層へ戻ります。開始層は終了層以下にしてください。

開始0、終了31、間隔2なら0、2、4、…、30と進みます。「終了層を含む」は上限を超えないという意味で、間隔と合わない31を追加表示することはありません。現在位置が奇数ならそこから間隔2で進むため、偶数層だけ見たい場合は再生前に層0へ移動してください。

ループOFFでは範囲内の最後の表示位置で停止します。読み込みが遅い場合は処理完了を待つため、指定速度より遅くなります。速度を合わせるための層の間引きは行いません。

「全層を先読み」は再生を始めずに先読みだけ実行します。先読みは同じサイズ・型の画像を対象とし、パレット画像には対応しません。先読みをOFFにした通常閲覧は可能です。処理後の段階はすでに全層計算済みなので、再生前の元画像先読みを必要としません。

### 異なる層の2点に追従する

1. 「再生・追従」タブを開き、1点目が見える層を表示します。
2. 点1の「画像上をクリックして指定」を押し、画像内の位置を左クリックします。
3. 別の層へ移動し、点2も同様に登録します。
4. 異なる層の2点が登録されると「経路に沿って中心を追従」がONになります。
5. 層を切り替えるか再生すると、経路上の位置が中央へ来るよう表示が移動します。中央には水色の十字が出ます。

数値を使う場合は、各点の層番号と元SPNG座標のX・Yを入力し、「入力した座標を登録」を押します。小数の座標も指定できます。値を入力しただけでは登録済みの点は変わりません。同じ層に2点を登録すると追従は有効になりません。

経路は層番号に対して直線補間します。物理的なZ座標を使ったフィットではなく、自動で飛跡を探索する機能でもありません。「2点の外側にも直線を延長」は初期状態ONです。OFFの場合、2点の層範囲外では近い端点のXY位置を保持します。

「再生範囲を2点の層に合わせる」で開始・終了を2点に合わせられます。「この点をリセット」はその点だけの入力と登録を消し、追従を解除します。別の経路へ変更するときは両点をリセットしてから登録すると、古い点との組み合わせで追従することを避けられます。

「全体表示」を押すと追従を解除します。重ね合わせ表示中は追従を表示せず、点のクリック登録も行えません。通常の層表示へ戻してください。

**追従は表示位置だけを動かします。** PNG出力や重ね合わせに経路に沿った位置合わせを適用する機能ではありません。

## 重ね合わせ・出力

### 対象層の書き方

「層の指定」は最大／最小合成と複数層PNG出力で共通です。再生範囲とは独立しています。対象は現在のSPNGと、「画像処理」タブの「表示データ」で選択した段階です。

| 入力例 | 対象 |
| --- | --- |
| `5` | 層5のみ |
| `0-31` | 層0～31 |
| `0-31:2` | 層0、2、4、…、30 |
| `1-31:2` | 層1、3、5、…、31 |
| `0-15,20,25-31` | 指定した範囲と単独層の和集合 |
| `0-10,5-15` | 層0～15。重複層は1回だけ |

結果は層番号の小さい順になります。範囲は開始≦終了、間隔は1以上で、実際の層番号内に指定してください。空欄、範囲外、逆順指定はエラーです。欠損層は計算・出力から除外します。

### 最大値・最小値を表示する

1. 「表示データ」で元画像または処理段階を選びます。
2. 「重ね合わせ・出力」タブで層を指定します。
3. 「最大値を表示」または「最小値を表示」を押します。

各XY位置で、指定層に含まれる画素値の最大または最小を選びます。明るい特徴を集めるには最大値、暗い特徴を集めるには最小値が適しています。画像の位置合わせや追従補正は行わず、同じXY座標同士を比較します。

同じ値の層が複数あれば、最も小さい層番号を採用します。指定した層数と、欠損を除いて実際に使った層数を表示します。全層が欠損なら合成できません。サイズ・型が同じ単一チャンネル画像が対象で、RGB等のカラー画像は合成できません。パレット形式の画像を指定した場合は色の明るさではなくパレット番号の比較になるため、濃淡の最大・最小として解釈しないでください。

「通常の層表示へ戻る」、層送り、表示データの変更で通常表示へ戻ります。

### 最大・最小になった層を色で示す

「最大・最小になった層の番号で色分け」をONにすると、値そのものではなく、その値を与えた層番号を色で表します。パレットは名前とカラーバーを見ながら選べます。

| パレット | 小さい層番号から大きい層番号への色 |
| --- | --- |
| kingfisher（初期値） | 青 → エメラルドグリーン → 緑・黄緑 → 金色 → 黄色 |
| meadow | 紫 → 青 → 緑 → 明るい黄色 |
| ember | 暗い紫 → 赤 → 黄色 |
| heat | 黒 → 赤 → 黄 → 白 |
| rainbow | 青 → 水色 → 緑 → 黄 → 赤 |

カラーバーの左端は**指定範囲の最小層番号**、右端は最大層番号です。欠損層があっても、この範囲で色を割り当てます。カーソル表示には極値の画素値と、それを与えた「選択層」が出ます。

「値で明度を変える（最小値は暗さで明度）」をONにすると、最大値合成では値が大きいほど明るく、最小値合成では値が小さいほど明るく表示します。OFFでは層番号の色だけで表示します。明度の基準は通常8bitで255、16bitで65535、最大値が1以下の単一チャンネル画像では1です。画像ごとに最小値から最大値へ引き伸ばす方式ではありません。

色分けは初期状態OFF、明度による重み付けもOFFです。色分けした結果を保存するとRGB PNGになります。詳しい配色と特性は[パレット](palettes_ja.md)を参照してください。

## スキャン設定の読み込み

「スキャン設定を自動読み込み（Layer別）」は初期状態ONです。画像を開くと設定値を読み込みますが、画像処理はまだ実行しません。「設定を現在のspngの全層へ適用」で実行します。

### 自動検出の場所

```text
撮像フォルダ/
  PARAMS/CombinedParam.json
  IMAGE/00_00/Raw_0_00000012_0_032.spng
  DATA/00_00/TrackHit2_0_00000012_1_000.spng
```

IMAGE／DATAが属する撮像フォルダで、次の優先順に検索します。

1. `PARAMS/CombinedParam.json`
2. `CombinedParam.json`
3. `ScanControllParam.json`

上位にIMAGE／DATAがない場所では、SPNGのあるフォルダとその上位2階層を調べます。綴りは`CombinedParam.json`であり、`ConbinedParam.json`は対象ではありません。

### Layerと手動選択

ファイル名から分かるLayerに対応する設定を使います。判定できない場合は「設定Layer」を指定します。通常は配列の0番目をLayer0、1番目をLayer1とし、明示的な`LayerID`または`LayerId`がある場合はその番号を使用します。

「設定JSONを選択」で別のJSONを指定できます。その指定は同じ撮像フォルダ内のファイル切り替えに使い、別の撮像フォルダを開くと自動検出へ戻ります。「自動検出をやり直す」は明示指定を解除して再検索します。

設定が見つからなければビューアの初期値を使います。該当Layerがない、Layer番号が重複、設定が不正、未対応Algorithm等の場合は理由を表示し、自動読み込みONのままでは画像処理を開始できません。別Layerの値を流用することはありません。

手動で調整した値をファイル切り替え後も保持するには、自動読み込みをOFFにします。ONのままではファイル切り替えや再読み込みで設定が更新されます。

### 読み込むパラメータ

| JSON項目 | 適用先 |
| --- | --- |
| `ImageFilterParam.Algorithm` | 補間の有無とGPU形式／CPU cubic |
| `ResizeFactor` | 補間倍率 |
| `NormCutOffFreq` | 2D filter |
| `WeightZFilter` | Z filter係数 |
| `ThrBinary` + `ThrBinaryPlus` | 二値化閾値。Plus省略時は0 |
| `Expansion` | 膨張サイズ。0または1は膨張なし |

FIR tap数は15、Z参照間隔は1に設定します。これらは画面で変更できます。設定ファイルの対応Algorithmや形式は[スキャン設定ファイル](scan_parameters_ja.md)にまとめています。

読み込み元パス、Layer、閾値の加算結果を画面で確認できます。数値は表示桁数を超える精度も保持し、その項目を変更しない限り読み込んだ精度で処理します。スキャン設定のファイル自体は書き換えません。

## 全層画像処理

### 適用と表示段階の選択

処理対象は**現在開いているSPNGの全層**です。「層の指定」や再生範囲で処理層を絞る機能ではありません。

1. 画像処理タブで設定を確認・変更します。
2. 「設定を現在のspngの全層へ適用」を押します。
3. 完了後に「表示データ」で元画像または中間段階を選びます。

順序は「補間後」→「2D filter後」→「Z filter後」→「二値化後」→「膨張後」です。無効な処理の段階は追加しません。ただし「補間後」は常に作られ、補間OFF／倍率1ではサイズを変えていない画像が入ります。完了時は最後の段階を表示します。

設定値を変更しただけでは計算済みの画像は変わりません。再度「全層へ適用」を押します。再適用は元SPNGから計算し、現在表示している処理後画像へ重ねてフィルタをかける操作ではありません。ただし、入力SPNG自体が処理済みなら、その画像から処理を始めます。

全層・全段階を計算して保持するため、完了後は各段階や層を切り替えられます。前の条件と新しい条件の結果を同時に保持して比較する機能はありません。必要な結果は条件を変える前にPNGへ保存してください。

### 設定一覧

初期値は設定JSONを読み込んでいない場合の値です。

| 設定 | 初期値 | 入力範囲・刻み・条件 |
| --- | --- | --- |
| 画素補間 | ON | OFFでは倍率を1として処理。入力欄の値は保持 |
| 補間倍率 | 1.4142 | 0.25～3、上下操作の刻み0.0001 |
| 補間方式 | GPU形式 A=-0.5 | CPU cubicも選択可能 |
| 2D filter：FIR背景 B − I | ON | 背景除去の有無 |
| FIR tap数（奇数） | 15 | 3～101の奇数。上下操作は1刻みのため偶数を選んだ場合は適用時にエラー |
| NormCutOffFreq | 0.1 | 画面入力0.001～0.499、刻み0.01 |
| Z filter | ON | 層方向フィルタの有無 |
| Z filter係数 | −0.2 | −5～5、刻み0.01 |
| Z参照間隔 | 前後1層（通常） | 前後2層（1層飛ばし）も選択可能 |
| 二値化（値 > 閾値を1） | ON | 値が閾値より大きい場合を1にする |
| 二値化閾値 | 9 | −1～255、刻み1 |
| 膨張 | ON | OFFではサイズ1として処理。入力欄の値は保持 |
| 膨張 n×n | 2 | 1～31。1は変化なし |

### 各処理の意味

**画素補間**は画像サイズを変えます。出力幅・高さは入力サイズ×倍率を整数へ丸めます。GPU形式はA=−0.5の整数原点cubic補間をCPUで計算するもので、GPUは不要です。CPU cubicはOpenCVのINTER_CUBICを使い、GPU形式とは計算規則が異なります。

**2D filter**はHamming窓付きFIRで滑らかな背景Bを求め、背景を8bitへ丸めた後、`H = max(B − I, 0)`を計算します。入力Iの背景より暗い部分は、Hでは正の明るい値になります。生画像で暗い銀粒子候補が、処理後に明るくなるのはこの差分のためです。NormCutOffFreqは空間周波数のカットオフで、0より大きく0.5未満を使います。XY端ではreflect101の反射境界を使います。

**Z filter**は前後の層を使って中心層の値を補正します。入力をH、係数をw、参照間隔をdとすると、両隣が範囲内にある場合は次の計算です。

```text
Z(z) = sat8_round[ H(z) + (w/2) × sat8[H(z−d) + H(z+d)] ]
```

`sat8`は0～255への飽和、`sat8_round`は丸めと飽和です。隣接画像の和も先に8bitで飽和します。丸めは最近接で、ちょうど中間の値は偶数へ丸めます。

端で片側だけが範囲内なら、その隣接層を係数wのまま使います。両側とも範囲外なら中心画像をそのまま使います。範囲内の参照層が欠損している場合は中心層で代用します。2D filterをOFFにした場合は、補間後画像がZ filterへの入力です。

**二値化**は`値 > 閾値`なら1、それ以外は0です。閾値と等しい値は0です。標準表示では1が白、0が黒になります。二値化された白画素がhit pixelです。「表示だけ白黒反転」を使った場合は見た目の白黒が入れ替わりますが、0/1の値は変わりません。

**膨張**はn×nの正方形でhit pixelの領域を広げます。2以上の膨張を行うには二値化もONにしてください。二値化OFFのまま膨張サイズ2以上を指定するとエラーになります。

### 対応範囲

全層処理は同じサイズの8bitグレースケール画像に対応します。16bit、カラー、パレット画像、1bit形式は通常表示・保存を利用してください。8bit形式で値が0/1の画像は8bitグレースケールとして扱います。

これらは可視化・調査用フィルタです。dead pixel補正、affine、走査マスク、撮像層の自動選別、tracking、MT／BTの再構成は行いません。

## PNGと処理記録の保存

### どの操作で何が保存されるか

| 操作 | 保存する画像 | 併せて作る記録 |
| --- | --- | --- |
| 表示層をPNG保存：元画像 | 現在の層全体 | なし |
| 範囲をPNG保存：元画像 | 現在の層のROI | なし |
| 表示層／範囲をPNG保存：処理後 | 現在の処理段階の画像／ROI | 同じ名前のJSON |
| 表示層／範囲をPNG保存：重ね合わせ | 最大／最小合成の画像／ROI。色分けONならRGB | 同じ名前のJSON |
| 保存先を選んで一括出力 | 指定した各層の元画像または処理段階 | 専用フォルダ内の`export_manifest.json` |

「表示層をPNG保存」はツールバーと「重ね合わせ・出力」タブにあり、同じ動作です。「表示層」と書かれていますが、重ね合わせ表示中は合成画像を保存します。

一方、**一括出力は各層を保存します**。色付き合成を表示していても、複数の合成画像や色分け画像を出力する操作にはなりません。

保存時には濃淡の表示範囲、表示だけの反転、画面の拡大率、選択枠、追従十字を含めません。1bit・8bit・16bitグレースケール、8bitカラーは対応する形式で保存し、RGBA・LAの透明度やP形式のパレット・透明度も保持します。2bit／4bitグレースケールは読み込み時に8bitへ展開し、P形式のインデックスは8bitで保存するため、入力PNGと圧縮形式・bit構成が同一とは限りません。

処理後はその段階の画素値を保存します。8bitの0/1画像も0/255へ拡大せず、0/1で保存するため、他の画像ソフトではほぼ黒く見える場合があります。

### 単一画像の保存

保存ダイアログで場所と名前を指定します。拡張子はPNGへ整えます。標準名には入力ファイル名、層番号、必要に応じて処理段階・合成範囲・ROIを付けます。既存PNGの保存先を選んだ場合は上書き確認に従ってください。

処理後・合成画像には同名のJSONを付けます。これは処理条件と出力の由来を確認するための記録です。同名JSONが既にあり、ビューアの出力記録と認識できない場合は保護のため保存を拒否します。別の名前を選んでください。

### 複数層を一括保存

1. 「表示データ」で保存対象を選びます。
2. 「層の指定」を入力します。
3. 切り出す場合はROIを指定し、「選択範囲だけを書き出す」をONにします。
4. 「保存先を選んで一括出力」で保存先の親フォルダを選びます。

その下に、入力ファイル名・日時・識別子を含む新しい専用フォルダを作ります。PNG名の`_z000`等は**元の層番号**で、選択した順に0から振り直すことはありません。欠損層はPNGを作らず、記録へ残します。

ROIは全層で同じ画像座標を切り出します。追従中でも切り出し位置を層ごとに動かしません。「選択範囲だけ」をONにして範囲未選択の場合は開始できません。

中止・エラー時は、それまでに保存された画像を残します。記録の`status`は`complete`、`cancelled`、`error`で区別されます。出力フォルダが残っているだけでは完了したとは判断せず、記録を確認してください。

### JSON記録の読み方

単一出力のJSONには入力SPNG、表示段階、層番号、ROI、処理条件を記録します。合成の場合は最大／最小の区別、指定層と使用層、色分け、パレット、明度重み付け、同値時の規則も含みます。処理条件には、適用したパラメータと、読み込み元スキャン設定があればそのパス・Layer・閾値の情報を記録します。

ROIは次の2種類で記録します。

| 項目 | 意味 |
| --- | --- |
| `ROI_bottom_left_xywh` | 左下原点のX、Y、幅、高さ。画面の入力と同じ意味 |
| `ROI_top_left_box` | 上原点の左、上、右、下。右と下は含まない境界座標 |

ROIを使わない場合はnullです。一括出力では左下の範囲を`metadata.crop_bottom_left_xywh`に記録し、指定層、保存されたファイル名・サイズ・mode、欠損層、終了状態も保存します。

JSONは出力を確認するための記録です。このJSONを読み込んで画面状態や追従点を復元する機能はありません。

## 用途別の操作例

### 32層から偶数層だけで16層相当を調べる

1. 32層SPNGを開き、Z参照間隔を「前後2層（1層飛ばし）」にします。
2. 全層へ画像処理を適用します。処理自体は32層分を計算し、偶数・奇数を独立に参照します。
3. 再生は開始0、終了30、間隔2にし、表示層を0へ移して開始します。
4. 合成・出力の「層の指定」は`0-31:2`にします。

奇数層を使う場合は開始1、終了31、間隔2、出力指定`1-31:2`です。物理的な撮像間隔や露光条件を変更する機能ではなく、既存32層から同じ偶奇を参照する操作です。

### 暗い粒子の位置を深さごとに色分けする

1. 表示データを元画像にします。
2. 対象層を指定し、「最小値を表示」を押します。
3. 層番号による色分けをONにします。
4. 暗い特徴を強調したい場合は「値で明度を変える」もONにします。
5. 「表示層をPNG保存」で色付き合成を保存します。

2D filter後や二値化後の明るいhit pixelを集める場合は、代わりに最大値を使います。

### 同じ条件の処理画像を保存し、条件を変えて比較する

1. 自動読み込みを確認し、必要ならOFFにして手動条件を固定します。
2. 全層へ適用し、目的の処理段階を選びます。
3. 必要な層を一括PNG出力します。
4. パラメータを変更して再度全層へ適用し、別の出力フォルダへ保存します。
5. `export_manifest.json`の適用条件を使って出力を区別します。

表示濃淡の変更だけでは処理条件の比較になりません。再計算後の「適用済み条件」と保存記録を確認してください。

## 処理の中止・ファイル切り替え・終了

先読み、全層処理、重ね合わせ、一括出力は進捗と「中止」を表示します。中止は処理の区切りで受け付けるため、押した瞬間に終了しない場合があります。処理中は競合する操作を無効にします。

別ファイルを開くと、再生を停止し、それまでの処理結果、先読み、重ね合わせ、追従点、ROIを解除します。古いファイルの非同期処理が遅れて完了しても新しい表示へ適用しません。手動設定値の保持はスキャン設定の自動読み込みON/OFFに従います。

アプリ終了時は進行中の処理を中止し、作業の終了を待って一時領域を解放します。設定や追従点を次回起動へ保存する機能はありません。残したい画像と処理条件はPNG出力を使って保存してください。

## 入力形式と作業領域

SPNGは、このアプリではPNGと長さヘッダを連結した形式を指します。ファイルを開くと層の索引を作り、必要な画像を順次展開します。詳しくは[SPNGの読み取り仕様](spng_format.md)を参照してください。

| 画像のmode | 意味 |
| --- | --- |
| L | 8bitグレースケール |
| 1 | 1bit二値 |
| I;16相当 | 16bitグレースケール |
| RGB | RGBカラー |
| RGBA | RGBと透明度 |
| LA | グレースケールと透明度 |
| P | パレット番号で色を表す画像 |

16bitカラーは値の損失を避けるため変換せず拒否します。形式が表示できても、全層処理・先読み・重ね合わせでの対応範囲は異なるので、各節の条件を確認してください。

入力SPNGは読み取り専用で開き、書き戻しません。アプリをローカルへコピーしたり、起動時にライブラリを展開したり、永続キャッシュを作ったりする機能はありません。

全層処理・先読みにはOSの一時領域を使います。中間画像を複数段階保持するため、圧縮されたSPNGのファイルサイズより大きな空き容量が必要です。倍率を2倍にすると1層のpixel数はおおむね4倍になり、層数や段階数に応じて領域も増えます。

一時領域はWindowsのdelete-on-closeで管理し、解放時やプロセス終了時に削除します。利用者が明示的に保存したPNG、JSON、診断出力は削除しません。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| フォルダを開いても画像がない | 対象のIMAGE／DATAまたはセンサーフォルダ付近を指定したか。深い階層を再帰検索する機能ではない |
| Viewが見つからない | 選択中のセンサー・Layer・画像種別に、そのViewが存在するか |
| 画像が空白 | 欠損層の表示ではないか。状態欄を確認して別の層へ移る |
| PNG保存が押せない | 読み込み中、欠損層、処理中ではないか。範囲保存ならROIを選んだか |
| 元画像では位置が合うが処理後の切り出しがずれる | 補間で画像サイズが変わっていないか。ROIは表示画像の座標で指定する |
| 追従しない | 異なる層の2点を登録したか。チェックがONか。通常の層表示か |
| 点の数値を変えても追従が変わらない | 「入力した座標を登録」で確定したか |
| 再生が遅い | 読み込みが指定速度に追いついていない可能性。先読み、画像サイズ、一時領域、ネットワークを確認する |
| パレット画像で再生前の処理が失敗する | 全層先読みをOFFにする。P形式は全層先読みに未対応 |
| フィルタの設定を変えても画像が変わらない | 再度「設定を現在のspngの全層へ適用」を押したか。表示データが元画像のままではないか |
| ファイルを変えると条件が戻る | 自動読み込みがONではないか。手動条件を維持する場合はOFFにする |
| 画像処理が押せない | スキャン設定の読み込み中・エラー、または別の全層処理中ではないか |
| フィルタを実行できない | 8bitグレースケールか、全層同じサイズか、FIR tapが奇数か、二値化OFFで膨張を指定していないか |
| 一時領域を確保できない | OSの一時フォルダの空き容量と書き込み権限を確認する |
| 保存した二値画像が他のソフトで黒く見える | 値は0/1で保存される。表示側で0～1を表示範囲にする |
| 色付き合成を一括出力できない | 一括出力は各層が対象。合成画像は「表示層をPNG保存」で保存する |
| 同名JSONが原因で保存できない | ビューアの処理記録以外のJSONを保護している。別の出力名にする |
